Case real • Sistema web publicado

Lava-Rápido VT

Um projeto criado para tirar o agendamento do improviso e organizar o atendimento em uma experiência simples para cliente e administração.

Problema

Agendamentos dependiam de contato manual e faltava uma forma organizada de visualizar os horários.

Solução

Foi criado um fluxo online para escolher serviço, data e horário, com painel administrativo para acompanhar os atendimentos.

Construído com

HTML, CSS, JavaScript, banco de dados e integração entre área do cliente e painel administrativo.
